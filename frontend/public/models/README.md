# 3D Brain Model Directory
You can optionally place an anatomical `brain.glb` file in this directory:
`/public/models/brain.glb`

The application includes an ultra-realistic, procedurally computed 3D anatomical brain split into four quadrant meshes with gyri/sulci folding, internal synaptic tracts, and silver PBR shaders. If `brain.glb` is placed here, the application can also parse its meshes or quadrant hierarchy!
